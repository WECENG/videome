# 功能与操作说明

适用版本：`0.1.0 Preview`。核对日期：2026-11-05。本文描述当前实现；平台验收结果见[双平台记录](CROSS-PLATFORM-IMPLEMENTATION-REPORT.md)。

## 1. 启动与工程入口

没有恢复记录时，App 打开名为“未命名工程”的空白工程：播放头从零开始，时间线没有片段和字幕，素材库与曲库没有占位文件。新工程初始时间线长度为 60 秒，之后可随编辑扩展。

已有本机恢复缓存时优先恢复上次内容。“项目 → 查看界面示例”会主动载入布局示例，标注“界面示例 · 无源文件”，不附带可播放的视频或音乐。旧缓存中的示例不会被自动删除，可从项目菜单新建空白工程。

| 入口 | 操作 |
| --- | --- |
| 项目 → 新建空白工程 | 清空当前时间线并保留素材库，先留存一份切换前快照 |
| 项目 → 打开工程… | 选择 `.videome` 文件；检查素材，缺失时可重新定位 |
| 项目 → 另存为… | 选择另一个文件位置，之后关联新路径 |
| 项目 → 恢复切换前的工程 | 恢复最近一次工程切换前的本机快照 |
| 顶部“保存” | 首次选择位置；已关联且名称匹配时写回当前工程 |
| “尚未保存 / 工程位置”或左上文件夹 | 查看完整路径、复制路径、在 Finder / 文件夹中定位 |

“工程位置与本地文件”面板区分当前工程文件、源素材和本机恢复缓存。该面板不是统一的工作区目录：

- `.videome` 保存设置、轨道、片段、字幕及素材路径，不嵌入或复制大型媒体文件。
- 源素材保留在导入位置。移动工程到另一台电脑时，也需迁移素材并重新定位。
- 尚未保存的编辑保存在本机恢复缓存，不等于已生成可独立管理的工程文件。
- 批量成片位于创建任务时选择的输出目录，可从批次的“输出目录”按钮打开。

## 2. 素材与曲库

### 导入和管理

点击素材库 `+`、选择素材区域或空白预览中的“导入第一个素材”；也可拖入文件。支持视频、音频和图片。桌面版读取时长、尺寸、编码、帧率、旋转等信息，并按需生成缩略图。

素材列表显示实际数量；没有内容时显示 0。选中时间线片段打开检查器后，左侧仍保留素材列表。搜索按名称、类型与编码筛选。

普通点击选择，`⌘/Ctrl + 点击` 多选，`Shift + 点击` 范围选择。“加入轨道”按选中顺序连续插入；双击素材快速加入轨道，拖动素材可指定插入位置。

素材菜单可复制源文件路径。移除仍被使用的素材时会确认并移除关联片段，不删除磁盘原文件。

### 音乐

“我的曲库”从用户导入的音频生成，不内置在线曲目或试听文件。可试听、加入背景音乐轨，设置音量、循环、淡入淡出和人声自动避让。修改只影响工程及导出，不改写源音频。

“智能配乐”当前按氛围、节奏、时长和许可声明等元数据规则排序。尚未接入音频语义模型、自动 BPM 识别或版权验证；确认许可只记录用户声明，不授予使用权，也不是持久的版权凭证。

## 3. 时间线与预览

默认轨道包括主视频、画面叠加、标题图文、字幕、原声/配音和背景音乐。点击“添加轨道”可选择视频、音频、标题图文或字幕类型；轨道较多时可纵向滚动，轨道名称与片段同步。

轨道旁的垃圾桶用于删除整条轨道。空轨道直接删除；有内容时会确认片段数量及其他轨道上的音画联动片段，锁定轨道及其联动内容需先解锁。删除保留素材库和源文件，支持撤销、重做。点击轨道图标或右键轨道名称可打开操作菜单，其中“清空轨道内容”会保留轨道，也可使用 `Shift+Delete`。

- 拖动片段移动位置，拖动边缘或修改入出点裁切。
- 在播放头处分割、删除片段或波纹删除并闭合后续空隙。
- 视频和原声可联动移动、分割，也可解除联动后分别编辑。
- 视频属性提供画面适应/裁剪铺满、缩放、水平偏移、旋转及原声音量。
- 时间线支持播放头定位、逐帧移动、缩放、水平滚动及适配整个工程。

桌面版优先预览原片。编码无法被 Chromium 播放时，可按需生成带音轨的 H.264 兼容代理；缩略图、帧和代理写缓存，不替换源文件。编辑预览不能替代导出后的合成结果检查。

## 4. 字幕与图文

手工新增、修改、删除字幕，设置起止时间、字号、底部间距和背景。当前可靠的文件入口为 SRT 导入和导出；文件选择器虽列出其他扩展名，不代表完整字幕格式兼容已经验收。

有手动字幕时，导入流程提供保留原内容为基础另存草稿的选择；确认载入会替换为导入字幕并同步时间线。导出字幕以当前 cue 列表为准。

标题图文和字幕可参与视频合成。导出使用随包的 Noto Sans CJK SC 字体，避免依赖 Mac 系统字体路径。

语音识别入口目前只检查是否有视频音轨并提示服务未接入，没有调用 Whisper 推理或完整模型探测。即使自行安装 `whisper.cpp`，当前入口也不会自动生成字幕。

## 5. 普通导出

时间线上至少需要一个可读取的真实视频片段；仅图片或仅音频工程暂不支持作为视频导出。

| 输出方式 | 实际编码与条件 |
| --- | --- |
| 原码流保留 | 单个兼容视频片段，可带其联动原声；不能有字幕、图文、额外混音或画面效果。切点依赖关键帧 |
| 日常高质量 MP4 / MOV / MKV | H.264 或 HEVC，音频使用 AAC |
| WebM | VP9 / Opus；HEVC 与 WebM 不兼容 |
| 无损中间文件 | FFV1 / PCM，使用 MKV；保存合成结果，不保留原始压缩码流 |

界面可选择常见横屏、竖屏、方形尺寸、工程帧率和视频码率。普通导出按工程时长及时间线内容确定范围；批量精确帧预算见[批量说明](BATCH-MIX.md)。

Mac 优先使用 VideoToolbox，遇到匹配的初始化/硬件错误时，清理本次临时输出并以软件编码重试一次；Windows H.264 / HEVC 使用 `libx264` / `libx265`，尚未接入 Windows GPU 编码。

导出前检查素材、预设兼容性和实际目标盘空间，执行期间写临时文件。普通导出结束主要用 ffprobe 检查是否存在视频流，不具备批量导出那样的逐帧与摘要验收。可在界面取消，失败时清理本次临时输出。

## 6. 批量混剪

右上角“批量混剪”提供“长视频 → 自动切片 → 随机重组 → 多条独立 MP4”。数量必填且支持 `1–1000`；默认片段约 3 秒、成片 30 秒、30 fps。支持种子复现、序列去重、自动或手动并发、暂停取消、重试与恢复。

关闭面板或刷新界面不会停止主进程任务；退出整个应用会中断活动任务，重启后需校验继续。成功结果可预览或重建包含源区间的可编辑代表工程。参数、文件布局与恢复规则见[批量说明](BATCH-MIX.md)。

## 7. 保存与恢复

当前会话将工程和关联路径一起存入 `videome-session`，读取旧版本缓存时选择较新的自动/手动保存记录。恢复缓存约在状态变化后 500 ms 写入；有素材或实际剪辑内容时，另有每 6 秒一次的自动保存任务。

已关联且名称匹配的工程还会自动写回 `.videome`。新建工程解除旧路径关联，切换前留存一个快照，避免空白工程自动覆盖旧文件。该快照只保存最近一次切换，不是多版本历史备份；重要工程仍应另存备份。

浏览器模式只使用自己的本地存储，不提供桌面文件打开/保存和批量队列。开发版、安装版及浏览器来源可能使用不同的恢复缓存；实际位置以桌面“工程位置”面板为准。

## 8. 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl + N` | 新建空白工程 |
| `⌘/Ctrl + O` | 打开工程 |
| `⌘/Ctrl + S` | 保存工程 |
| `⌘/Ctrl + Shift + S` | 另存为 |
| `⌘/Ctrl + Z` | 撤销 |
| `⌘/Ctrl + Shift + Z` 或 `⌘/Ctrl + Y` | 重做 |
| `Space` | 播放/暂停 |
| `S` | 在播放头处分割 |
| `I` | 打开字幕编辑 |
| `Delete/Backspace` | 删除当前片段 |
| `Shift + Delete/Backspace` | 清空当前轨道 |
| `←/→`、`Shift + ←/→` | 按帧、按秒移动播放头 |
| `⌘/Ctrl + 滚轮`、`Shift + 滚轮` | 缩放、横向滚动时间线 |

在输入框、文本编辑区和下拉框中编辑时，不触发这些全局快捷键。
