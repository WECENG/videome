# Videome 功能说明

本文档描述 `0.1.0 Preview` 已实现的用户功能、操作路径和已知边界。它以当前源码为准，不把规划中的 AI 能力当作已交付功能。

## 1. 工作区

Videome 编辑器由左侧工具栏、素材库、中央预览/编辑区、右侧属性检查器和底部多轨时间线组成。

- **剪辑**：素材、预览、时间线和片段属性。
- **字幕**：字幕行编辑、SRT 导入/导出和字幕样式。
- **智能配乐**：本地授权音乐的试听、推荐参数和自动混音。
- **画幅**：项目画幅、声音和导出相关设置。

项目名称、保存状态、撤销/重做和导出入口位于顶部栏。

## 2. 素材库

### 导入

支持视频、音频和图片素材。可以使用以下方式导入：

1. 点击素材库顶部 `+` 打开文件选择器。
2. 点击拖放区域选择文件。
3. 将本地文件拖入拖放区域。
4. 在属性检查器的快速入口中直接添加视频到时间线。

桌面版导入时会读取文件大小、时长、分辨率、编码、帧率、旋转信息和缩略图。浏览器预览不能完全替代桌面文件选择器和本地媒体 IPC。

### 选择与加入轨道

- 普通点击选择单个素材。
- `⌘/Ctrl + 点击` 进行多选，并记录点击顺序。
- `Shift + 点击` 选择范围。
- 素材行上方的 `加入轨道` 会把选中素材按点击顺序从左到右连续插入。
- 直接拖动素材到时间线，会使用拖放位置作为插入起点。
- 双击素材可快速加入单个片段。

素材库中的选择序号和时间线片段右上角的序号用于表达当前选择顺序；取消选择后序号会重新压缩。

### 素材管理

- 支持按名称、类型和编码搜索。
- 可复制源文件路径。
- 从素材库移除素材时，如果素材仍被时间线引用，会同时移除关联片段，但不会删除磁盘原文件。
- 打开旧工程时，如果源文件移动或丢失，会进入重新定位流程。

## 3. 时间线编辑

### 轨道类型

- 主视频
- 画面叠加
- 标题图文
- 字幕
- 原声/配音
- 背景音乐

### 编辑操作

- 拖动片段移动位置；联动的视频原声会同步移动。
- 拖动片段两侧边缘调整入点/出点。
- 将播放头放到片段内部后点击 `分割`，或按 `S`。
- `删除` 删除当前片段；`波纹` 删除并闭合后续空隙。
- 轨道可以锁定或静音，也可以清空整条轨道。
- 选择视频片段后，可以链接或解除视频与原始音频。
- 时间线底部支持缩放、适配整个工程和水平滚动。

### 画面属性

选中视频或图片片段后，可以调整：

- 画面填充（适应画布/裁剪铺满）
- 缩放比例
- 水平/垂直位置
- 旋转
- 原始收音音量

## 4. 预览与兼容性

- 支持播放头定位、逐帧前进/后退、播放/暂停和跳转剪辑点。
- 桌面版优先播放本地原片；Chromium 无法解码的编码会尝试生成带音频的 H.264 预览代理。
- 视频帧和缩略图使用缓存，缓存不会覆盖原始媒体。
- 预览失败不会删除源文件；界面会显示无法读取的原因或建议创建代理。

## 5. 字幕

- 手工新增、编辑、删除字幕行。
- 调整字幕起止时间和字号、底部间距、背景开关。
- 导入 SRT 时可以替换现有字幕，也可以保留原字幕并将新文件作为草稿。
- 可将当前字幕导出为 SRT。
- 导出成片时，字幕按照时间线和项目字幕设置烧录到视频。

### 语音识别边界

界面预留本地 Whisper 检查入口，但当前仓库不内置 Whisper 模型。未安装 `whisper.cpp` 和模型时，程序会明确提示而不会伪造识别结果。

## 6. 音乐与混音

- 音乐库只分析用户导入的本地音频，不提供未授权的在线曲库。
- 支持试听本地音频、记录曲风/BPM 等元数据。
- 添加音乐后可循环铺设到工程时长。
- 支持音量、淡入、淡出和人声自动避让参数。
- 音量和混音修改只写入工程，不修改原始音频文件。

## 7. 导出

导出面板提供三种预设：

| 预设 | 说明 |
| --- | --- |
| 原码流保留 | 仅适合兼容的单一视频流切割；不能包含字幕、图文、额外音轨和画面效果 |
| 日常高质量 | H.264 推荐模式，适合常规编辑、字幕和多轨混音 |
| 无损中间文件 | FFV1 无损输出，文件体积较大 |

可配置：

- 视频编码：H.264 或 HEVC（高质量模式）。
- 容器：MP4、MOV、MKV、WebM。
- 画幅：1920×1080、3840×2160、1080×1920、1080×1080。
- 比特率：6、12、20、35 Mbps。

导出前会检查素材路径、轨道状态、编码兼容性、磁盘空间和原码流条件。导出过程写入临时文件，完成后使用 FFprobe 验证输出视频流。

## 8. 工程与保存

- 桌面版可通过文件菜单保存/打开 `.videome` 工程。
- 工程文件记录项目设置、轨道、片段、字幕和素材引用路径。
- 自动保存写入本地浏览器存储；桌面版保存为工程文件时不会上传数据。
- 工程只保存源文件路径和元数据，不把大型媒体文件复制进工程。

## 9. 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl + S` | 保存工程 |
| `⌘/Ctrl + Z` | 撤销 |
| `⌘/Ctrl + Shift + Z` 或 `⌘/Ctrl + Y` | 重做 |
| `Space` | 播放/暂停 |
| `S` | 在播放头处分割 |
| `I` | 打开字幕编辑 |
| `Delete/Backspace` | 删除当前片段 |
| `Shift + Delete` | 清空当前轨道 |
| `←/→` | 按帧移动播放头 |
| `Shift + ←/→` | 按秒移动播放头 |
| `⌘/Ctrl + 滚轮` | 缩放时间线 |
| `Shift + 滚轮` | 横向滚动时间线 |
