# 批量自动混剪

桌面右上角的「批量混剪」可以从一个本地长视频生成 1–1000 条独立 MP4。生成数量由用户填写，不预填固定条数；默认片段约 3 秒、成片 30 秒、30 fps，保留原声。

## 使用流程

1. 选择视频与输出目录，设置时长、数量、种子和并发。
2. 点击「分析并生成方案」。应用读取源视频指纹、镜头切点及有效视频时长，提前生成并保存全部唯一序列。
3. 确认实际帧对齐时长与空间估算，点击「开始生成」。关闭面板后任务继续运行。
4. 在批次历史中查看进度、暂停、取消或继续；失败项可重试。重启应用后可对中断批次执行「校验并继续」。
5. 结果支持预览、复制路径及「编辑代表时间线」。代表工程包含原始切片和联动原声，载入前会保存当前工程的独立恢复快照。

## 精度与去重

输出帧数是 `round(请求秒数 × fps)`。30 秒、30 fps 必须产生 900 帧。整数输出帧率支持 24、25、30、50、60；输入允许 VFR、小数帧率和旋转元数据。原声统一为 48 kHz，迟到或提前结束的原声区间补静音，纯视频源没有音轨。

镜头识别保持原始帧时间戳，缩小画面后检测。切片优先选择固定边界附近的镜头切点，检测失败会明确显示固定切片降级。

同一算法版本、素材、参数和种子生成相同剪辑序列。批次内按片段 ID、源区间、使用帧数及顺序去重；组合不足时分析终止，不使用重复序列补足数量。素材用完后重新洗牌，只有单片段素材允许连续重复。此规则不限制不同结果之间的素材重合率。

单条最多 64 个片段。首版输出 SDR、H.264/yuv420p、AAC、MP4，默认视频 12 Mbps、音频 256 kbps；HDR 被拒绝。画幅在创建批次时从当前工程复制。编码器不同不保证文件逐字节相同。

## 并发与资源

自动模式默认 1 路。至少 4 核、16 GiB 总内存，输入和输出均不超过 1080p/30 fps，且每条不超过 16 段时最多 2 路；前两条始终先单路执行。手动上限 1–8 路，校验也占槽位。每次执行一个批次，其余批次排队，普通导出与批次共用资源锁。代理和缩略图在后台串行执行，批次期间延后处理。

VideoToolbox 初始化失败时以 libx264 重试一次；自动模式后续降至 1 路。磁盘满、目标盘不可用和权限错误暂停整批；单条媒体错误只影响该结果。更多并发不保证更快。

暂停让活动输出完成并停止领取新任务；取消终止活动子进程、清理临时文件并保留成功结果。SIGTERM 后 5 秒仍未退出的子进程会收到 SIGKILL。媒体进程由独立守护包装器启动，主进程被强制退出导致 IPC 断开时也会清理 FFmpeg。

## 文件与恢复

每批输出到独立 `Videome-时间-批次ID` 目录，其中包含 `mix-0001.mp4` 等文件、`batch-manifest.json`、CSV 及按需创建的 `.videome` 工程。200 条、30 秒、默认码率预算约 9.19 GB，开始前和派发时检查实际输出盘，预留 20% 空间。

权威清单位于 Electron `userData/batch-mix/<jobId>/job.json`，保留 `.bak`。状态通过单写入队列持久化。视频完整解码、验证流和帧数后才发布正式文件；已有无关同名文件不覆盖。恢复时重新校验源 SHA-256，成功输出按 SHA-256 跳过，发布与状态提交之间中断的文件重新协调。源文件内容变化拒绝续跑；源路径迁移可由 `resumeBatchMix({ jobId, sourcePath })` 关联内容相同的文件。

当前工程恢复快照位于 `userData/batch-project-recovery/`。清理任务记录保留最终输出和输出目录清单。

## 验证命令

```sh
npm test
npm run build
node scripts/batch-acceptance.cjs /absolute/source.mp4 /absolute/output-directory
node scripts/desktop-batch-smoke.cjs
npm run dist:mac
node scripts/desktop-batch-smoke.cjs dist/mac-arm64/Videome.app/Contents/MacOS/Videome
```

性能验收脚本分别运行 1/2/4 路各 4 条及 2 路 200 条，输出 640×360、30 秒、900 帧，报告写入 `acceptance-report.json`。输入保持原始解码分辨率，报告包含耗时、产出速度、采样峰值 RSS、失败率、唯一签名和实际文件大小。峰值 RSS 包含 Node 与直接子进程，不包含系统硬件媒体服务的共享内存；并发对比可能受其他本机负载影响。
