# 本地智能配音计划

状态：方案已确认；实现与验收状态以仓库代码及测试为准。  
更新日期：2026-11-11

## 当前实现状态

本计划描述智能配音的模型和处理链路；当前用户可见功能说明以[功能与操作说明](FEATURES.md)为准，工程模块和 IPC 边界以[架构与数据流](ARCHITECTURE.md)为准。当前仓库已经包含配音任务、字幕识别、草稿管理、中文配音/保留背景入轨和曲库排除 `dubbingSource` 音频的实现。配音生成的音频属于工程素材，不会进入普通“我的曲库”。

本文件中的模型版本、性能指标和验收清单仍是配音能力的方案约束；只有代码和测试已经覆盖的行为才视为已交付。配乐工作台、本地 BGM 分析和视频推荐属于独立功能，详见[功能与操作说明](FEATURES.md)中的“智能配乐工作台”和“本地智能识别与推荐”。

## 目标与范围

为 Videome 增加全本地智能配音首版。处理时间线中选中的一个或多个含音频片段，将英文对白转为中文；用户校对识别文本和译文后，生成中文语音并把配音与保留的背景声作为独立音轨加入时间线。多个片段按时间线顺序排队，完成后可一次性入轨。

首版面向 Apple Silicon Mac，不上传音视频或文本。所有对白使用一个可选的预设中文音色。保持视频和时间线时长不变，保留原始媒体；不包含声音克隆、自动说话人识别、口型同步或其他目标语言。

## 本地处理模型

| 阶段 | 选型 | 用途 |
| --- | --- | --- |
| 人声分离 | [MERL MRX](https://github.com/merlresearch/cocktail-fork-separation) | 将音频分成对白、音乐和环境音，组合音乐及环境音作为保留背景 |
| 英文识别 | [whisper.cpp small.en](https://huggingface.co/ggerganov/whisper.cpp) | 识别英文并生成逐句时间戳 |
| 中文翻译 | [Qwen3-4B Q4_K_M](https://huggingface.co/Qwen/Qwen3-4B-GGUF) 与 llama.cpp | 本地翻译，结合相邻句提供上下文，关闭思考模式 |
| 中文语音合成 | [Kokoro v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh) 与 [sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html) | 快速本地模式；按短语速度和停顿规划生成 |
| 音频加工 | 现有 FFmpeg | 转换采样率、保调变速、补静音并准备可入轨音频 |

模型、运行环境和运行时文件由应用首次使用时按需下载，界面显示下载进度及磁盘空间需求。资源采用固定版本和校验值，保存在应用数据目录，提供校验失败和下载中断后的重试。完成安装后，模型推理不需要网络。识别、翻译、语音合成及分离应串行运行，并在阶段之间释放模型；MRX 首版使用 CPU，识别与翻译使用可用的 Metal 加速。模型约需 3GB，运行环境和临时文件空间另计。实际耗时及资源占用须先在 Apple Silicon Mac 上测量。字幕另用多语言 Whisper small 模型，可从字幕面板独立安装和修复；它与配音模型共用私有 Python 及安全下载设施，不下载翻译、分离、语音合成或 llama.cpp 资源，英文配音继续使用 small.en。

智能配音安装面板提供沿用环境、直连和自定义 HTTP/HTTPS 代理，代理同时用于模型及 Python 依赖下载，提供 GitHub、Hugging Face、PyPI 站点连通性检查。代理设置仅保存在本机应用数据目录，认证信息加密存储；安装开始后固定本次配置，修改需先取消再继续。字幕 Whisper 安装复用同一代理设置，并与其他模型安装互斥。

## 用户流程

1. 用户在时间线上选择一个或多个视频、音频或已独立分割的原声音频片段，打开“智能配音”面板；同时选中联动视频和原声时只处理更精确的原声音频。
2. 应用校验模型安装情况，提取所选片段的裁剪范围，并分离对白、音乐及环境音。
3. 应用识别英文并翻译成中文，显示逐句英文、时间戳和可编辑的中文草稿。
4. 用户校对译文，试听识别文本或背景；可修改译文、试听单句配音并单独重新生成。
5. 用户选择表现后端、预设中文音色、情绪、语速和停顿，并点击“入轨”。应用验证来源片段仍有效，检查相关轨道锁定状态，再将配音和背景作为两条独立音轨加入时间线。也可使用“一键识别并入轨”跳过人工校对。

翻译和识别结果在人工校对前不生成配音，也不写入工程。批量任务逐段保存草稿并串行执行，避免多个本地模型任务同时占用资源。自动韵律规划会按标点和句式拆分短语，插入停顿，并对不同情绪、问句和感叹句应用轻微速度变化；每句可单独微调情绪、语速和停顿。默认同步添加中文字幕，可在入轨前关闭；字幕复用最终译文和配音句子的时间戳，追加并保留原有字幕及样式，不复用 `linkedClipId`。整批配音、背景和字幕入轨作为单个可撤销操作。

配音后端包括本地韵律增强、本地快速模式和 OpenAI 兼容云端。云端模式只有在用户主动配置接口地址、模型、音色和加密保存的 API Key 后才发送文本；未配置时任务会明确失败，不会静默回退到云端。

## 时间线与声音规则

- 只处理用户选中片段的有效裁剪区间；不会自动恢复已删除的独立原声音轨。
- 视频选区只有在能从当前时间线确定对白来源时才能处理。如果对应原声音频已删除或被分割到无法唯一确定，提示用户选择具体音频片段。
- 按识别时间戳生成逐句配音片段。较短译文保持自然语速并补静音；较长译文最多加快至 1.25 倍。仍超出对应句段长度时标记该句，要求缩短译文后重试，不截断对白，也不延长视频或移动后续片段。
- 背景音轨覆盖所选区间，来自分离出的音乐和环境音。分离可能导致人声残留，或损失部分背景声，需提供试听；不承诺无损分离。
- 入轨时仅静音相应范围内的源对白。源轨道有锁定片段需要修改时，阻止入轨并提示解锁；已静音的锁定视频不需要修改。区间外的原声和其他音乐保持不变。
- 保留现有原声音量默认值、音画联动、轨道锁定、撤销／重做、工程保存和导出时长语义。

## 桌面端接口与任务数据

模型推理只在 Electron 主进程或受控本地子进程执行。通过 preload IPC 提供模型状态与安装、任务创建与查询、取消、文本更新、配音生成及进度订阅。渲染进程不直接启动命令或访问模型文件。

后台任务持久化来源片段快照、裁剪范围、逐句文本、模型版本、处理阶段和生成文件路径。应用重启后可恢复草稿，并重试未完成阶段；失败或取消不会修改工程。入轨前若项目或来源片段与生成时的快照不匹配，需重新确认或重做。

配音草稿列表支持逐条删除和清空当前工程的列表，操作前确认。运行中的任务需先取消并等待停止；清空不会移除其他工程的草稿。删除草稿后不再恢复该草稿，已生成音频继续保留，保证已入轨片段、保存工程及撤销记录引用的文件仍可读取。

生成音频保存在应用持久素材目录，作为普通路径素材被工程引用，不嵌入 `.videome` 文件。新增的配音来源元数据用于识别生成文件，但不得改变通用音频片段的分割、删除或联动逻辑。模型运行时、模型文件、临时文件和用户生成素材应分开存放。

## 实施与验收

先以固定的英文对白、音乐和环境音样例跑通处理链路，记录单个样例的总耗时、分阶段耗时、峰值内存及背景残留，再接入界面。验收至少覆盖：

- 选择视频、独立音轨、被裁剪片段、无音轨片段、静音片段及无对白片段。
- 英文识别时间戳、相邻句翻译上下文、译文修改、单句重新生成和超过 1.25 倍上限的句子。
- 模型未安装、校验失败、下载中断、离线重试、磁盘不足、取消任务及应用重启后的草稿恢复。
- 入轨时只静音目标范围，拒绝修改锁定来源，保留范围外原声及其他音轨，撤销／重做和保存重开保持一致。
- 无网络情况下完成识别、翻译、配音、试听和入轨；时间线播放、拖动指针及导出同步，导出成片时长误差不超过一帧且无额外黑屏尾段。
- 回归既有音轨分割、删除、锁定轨道和导出测试。
