## 2. 已实现的模块与行为

- 共享工具定位、编码器选择、字体、滤镜路径、Windows 文件名和子进程终止逻辑。打包运行只使用随包媒体工具。
- Mac H.264/HEVC 优先 VideoToolbox，匹配初始化失败时软件重试一次；Windows 使用软件编码。
- Mac 15 媒体资源锁文件固定来源、版本与摘要；Tesseract 使用 5.5.2，避免较新 bottle 要求 macOS 15.8.1。
- Noto Sans CJK SC 及许可随包分发，标题、字幕和封面文字无需 Mac 系统字体路径。
- 批量队列、独占发布、文件刷新/替换、目录能力检查、主进程异常恢复和 Windows 进程树终止适配。
- 手动触发的 GitHub Actions 原生构建矩阵、安装版/免安装版、媒体资源归档、构建信息、摘要、日志和人工验收材料。

源码结构和接口见[架构](ARCHITECTURE.md)，命令与环境见[开发与交付](DEPLOYMENT.md)。

## 4. 工程入口与桌面验收

默认空白启动，示例只从项目菜单主动打开且明确标注无源文件。移除素材计数“04”和虚构曲库；打开检查器后左侧素材列表保持可见。

开发版与安装版使用独立测试用户目录验证：

- 首次空白工程、素材数 0，导入真实素材并加入时间线。
- 保存、另存为、打开、刷新恢复，工程与保存路径保持一致。
- 完整路径展示、复制入口、Finder 定位及缓存/素材位置说明。
- 新建空白后等待自动备份，原工程文件内容不变，已导入素材保留；自动备份只保留同目录最新的 `.autosave-时间戳.videome` 副本。
- 示例如实标识，恢复切换前工程后路径与片段恢复。
- 1120 / 1680 宽度下菜单、位置和素材区可见，未捕获界面脚本错误。

批量开发版与安装版完成 3 条 × 6 秒输出，每条 180 帧，代表时间线可预览；普通中文标题和字幕 H.264 导出成功。安装应用关键源码/资源与该轮工作区构建一致，用户原工程和恢复缓存保留。
