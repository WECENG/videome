# 批量分段

“批量分段”用于将一个本地视频按固定片段时长，从头到尾顺序输出为多个独立 MP4。

## 使用方式

1. 选择源视频和输出目录。
2. 输入片段时长（`0.1–3600` 秒）。
3. 点击“分析并创建分段任务”，确认自动计算的分段数量。
4. 点击“开始分段”，可在执行期间暂停或取消。

分段数量由源视频时长自动决定。视频时长为 120 秒、片段时长为 20 秒时生成 6 段；视频时长为 125 秒时生成 7 段，最后一段为 5 秒。最后的短尾不会丢弃，也不会补黑帧或冻结画面。

## 输出与音频

每次任务在所选目录创建唯一的 `Videome-分段-时间-批次ID/` 子目录，文件名为 `源文件名-分段-0001.mp4`。输出统一为 H.264、`yuv420p`、MP4 `faststart`，画幅、帧率和旋转方向保持源视频参数。源视频有音轨时按同一时间区间保留原声，没有音轨时不创建音轨；本功能不添加背景音乐。

批次目录包含所有已发布分段、`batch-manifest.json` 和 `batch-manifest.csv`。每段在发布前都会完成媒体解码、视频流、帧数、时长、音频流和 SHA-256 校验。

## 任务与限制

任务状态和进度保存在 `userData/batch-segment/<jobId>/job.json`，与批量混剪共享媒体资源锁，但使用独立任务目录和 IPC 命名空间。暂停会停止派发新分段并允许当前分段完成；取消会终止活动 FFmpeg 并清理临时文件，已完成文件保留。暂不生成 `.videome` 工程，不提供随机重组、场景检测、背景音乐或失败项重排。
