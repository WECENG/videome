200 条总文件大小 2,199,018,117 字节，约 2.05 GiB。每个结果均通过完整解码、流信息、帧数及音视频结束时间校验，清单保存 SHA-256。原始报告和生成视频保留在项目的 `output/batch-acceptance/`（Git 忽略）。

测试期间有打包和其他回归测试并行运行，因此以上耗时为本次机器负载下的实测记录，不能用于推算独占机器性能，也不能代表 1080p 或 4K 输出吞吐。原始 RSS 记录只采样 Node 与直接子进程，不含系统硬件媒体服务，不能当作整机峰值内存；后续脚本已改为遍历子进程树。

## 正确性与恢复

完整回归共 60 项测试通过，覆盖领域函数、媒体执行、200 项调度、故障恢复及现有工程行为；构建和 `git diff --check` 通过。

- 已知红蓝画面重排、900 帧、音轨补齐和纯视频输出。
- VFR、非零起始时间戳、旋转元数据、原声提前结束，以及 HDR 拒绝。
- VideoToolbox 初始化失败后软件编码回退。
- 原始切片代表工程可重新导出；修复后续视频黑屏、多段原声滤镜以及短切片被旧导入修复扩长的问题。
- 200 项队列限制并发，暂停、取消、失败项重试、源内容变化拒绝恢复及同名输出保护。
- 强制退出发生在编码前、校验中、发布前和发布后，重启均可恢复；已经发布的成功文件没有重新覆盖。
- JSON 截断后从备份恢复。

## 桌面与打包

开发版和 macOS arm64 目录包均完成「打开批量面板 → 分析 → 生成两条 6 秒视频 → 载入代表时间线」，输出各 180 帧，界面没有错误通知。

FFmpeg/ffprobe 共收集 93 个二进制及动态库，改写为应用内部相对引用；打包版在仅包含 `/usr/bin:/bin` 的 PATH 下使用应用自带工具完成上述流程。已检查 ASAR 内入口及媒体模块的内容与校验摘要。

这属于本机打包验证，尚未在没有安装 Homebrew 的另一台 Mac 上验收；应用未做 Developer ID 发行签名或公证。
